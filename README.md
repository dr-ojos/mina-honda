# Mina Honda

Un buscaminas de profundidad: pica, recoge gemas y baja piso a piso.

**Jugar:** https://dr-ojos.github.io/mina-honda/

- Tres vidas: una mina te quita una vida, no la partida.
- Combos que multiplican el oro hasta ×5.
- Gemas, cofres y una escalera escondida en cada piso.
- Almacén entre pisos con sonar, detector, linterna, cascos y vidas.

Todo el juego está en un solo archivo, `index.html`. También se puede descargar y abrir con doble clic en cualquier navegador.
